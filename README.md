🎮 Tic-Tac-Toe in C++
A simple two-player Tic-Tac-Toe game developed using C++.

Features:
Two-player gameplay
3×3 game board
Player turns alternate between X and O
Checks rows, columns, and diagonals for a winner
Detects a draw
Prevents players from selecting occupied positions

Concepts Used:
C++ functions:To display the board and check the winner.
2D arrays:To represent the 3×3 game board.
Loops:To repeat turns and check winning conditions
Conditional Statements – To manage player turns, validate moves, and determine the winner.
Boolean values:To indicate whether a player has won.
User Input and Output – Using cin and cout to interact with players.
Operators – Arithmetic (/, %), comparison (==), logical (&&, ||), and assignment (=) operators.
Break and Continue – To end the game or retry an invalid move.
Basic game logic

How to Play:
Run the program using a C++ compiler.
Players take turns entering positions from 1 to 9.
The first player to get three symbols in a row, column, or diagonal wins.
If all nine positions are filled without a winner, the game ends in a draw.

Language:
C++
